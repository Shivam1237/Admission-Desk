# AI Usage Report

## AI Tool Used

OpenAI Codex.

## What I Asked AI to Do

1. Generate the application architecture for a simple admission lead management MVP.
2. Implement the frontend and backend in one Next.js application.
3. Create the MongoDB/Mongoose models, seed data, and API routes.
4. Implement validation, dashboard metrics, charts, ageing, follow-ups, and reports.
5. Debug and test the application, including the production build.

## Prompt That Was Most Useful

The most useful prompt was the complete assignment brief: build a simple end-to-end Admission Lead Management System with lead CRUD, counsellor assignment, source/status tracking, activity history, follow-ups, ageing, dashboard visibility, reports, seed data, API routes, README, and an AI usage report.

## Code Generated by AI

AI generated the initial Next.js application structure, TypeScript components, page layouts, CSS, API route handlers, Mongoose Lead and User models, validation helpers, metrics helpers, seed data, and supporting documentation.

## Code Modified or Validated

The implementation was reviewed and validated around the lead update flow, duplicate phone handling, partial updates for quick status/counsellor changes, date handling, follow-up buckets, zero-lead report calculations, responsive layout, and production build configuration.

## AI Output That Was Wrong

During the first build attempt, the generated layout used a remote Google font through `next/font`. The production build tried to fetch that font and failed in the local environment.

## How I Identified the Problem

`npm run build` reported a font fetch error during the Next.js build. The failure was reproducible from the build output before application pages were compiled.

## How I Fixed It

The remote font dependency was removed from the layout and the application now uses a local system font stack in `app/globals.css`. This keeps the build independent of external font downloads.

## Validation Performed

- `npm run seed` inserted 18 leads into the local MongoDB instance.
- `npm run lint` passed with `tsc --noEmit`.
- `npm run build` passed and produced all requested pages and API routes.
- The development server served the login, dashboard, and leads pages with HTTP 200.
- HTTP smoke tests passed for lead creation, partial status update, activity creation, search/filtering, follow-up completion, deletion, invalid IDs, invalid payloads, and duplicate phone handling.
